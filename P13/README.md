# P13: Choosing between Flexbox and Grid

This page compares Flexbox and CSS Grid by arranging the same three items with both method.

Flexbox is set up to wrap items along a row. Grid creates responsive columns with `repeat()`, `auto-fit`, and `minmax()`.

The HTML is in `index.html`, and the layout rules are in `style.css`.

Open `index.html` in a web browser to compare the two layouts.
