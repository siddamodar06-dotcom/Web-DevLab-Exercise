# P2: Portfolio repo with an initial commit

## Goal
Create a Git repository for the portfolio and record the first version in a commit.

## Steps
1. Open Terminal in the portfolio project folder.
2. Initialize Git with `git init`.
3. Check the files Git sees with `git status`.
4. Stage the portfolio files with `git add README.md index.html`.
5. Create the initial commit with `git commit -m "Initial portfolio commit"`.

## Practice commands
```bash
git init
git status
git add README.md index.html
git commit -m "Initial portfolio commit"
```
