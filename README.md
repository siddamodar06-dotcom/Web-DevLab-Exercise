# Web DevLab Exercises

A collection of projects practicing terminal navigation, Git and GitHub workflows, HTML, and CSS.

## Projects

### Module 1: Terminal, Git, and GitHub

- **P1 — Project folder and terminal navigation:** Create folders and practice basic Terminal commands.
- **P2 — Portfolio repo with an initial commit:** Initialize Git, stage project files, and create the first commit.
- **P3 — Feature-branch Git workflow:** Make a change on a feature branch, push it, and open a pull request.
- **P4 — GitHub README and version tags:** Document a project and mark a version with a Git tag.

### HTML and CSS

- **P5 — Semantic bio page:** Build a simple bio page with semantic HTML.
- **P6 — Portfolio page structure:** Organize portfolio content with semantic HTML sections.
- **P7 — Quadratic equations:** Present an explanation using HTML and inline CSS.
- **P8 — Sticky navbar and card overlay:** Arrange cards with Flexbox and positioned titles.
- **P9 — Responsive navbar and card grid:** Use Flexbox wrapping for navigation and cards.
- **P10 — Portfolio header and footer:** Practice arranging and wrapping content with Flexbox.
- **P11 — Newspaper-style layout:** Create a three-column layout using CSS Grid.
- **P12 — Portfolio grid with named areas:** Arrange projects and hobbies with named CSS Grid areas.
- **P13 — Flexbox and Grid comparison:** Compare how Flexbox and CSS Grid arrange the same items.

## Viewing the pages

Open a project's `index.html` in a web browser. For example, open `P13/index.html` to view P13.

Projects that include a `style.css` file use it for their page styling.
