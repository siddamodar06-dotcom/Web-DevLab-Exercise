# P12: Portfolio grid with CSS Grid area

This page uses named CSS Grid areas to arrange a projects heading across three columns, three project cells, a hobbies heading across three columns, and three hobby cells.

The first project cell contains the known project, `Web-Dev-Lab-Exercises`. Project 2 and Project 3 are placeholders. The hobbies use the details Satva provided.

The HTML is in `index.html`, and the named Grid areas are defined in `style.css`.

Open `index.html` in a web browser to view the page.
