# P1: Project folder and terminal navigation

## Goal
Create a project folder and practice moving between folders in Terminal.

## Steps
1. Open Terminal in the location where you keep your projects.
2. Check the current location with `pwd` and list its contents with `ls`.
3. Create a folder with `mkdir my-project`.
4. Enter it with `cd my-project`.
5. Use `pwd` and `ls` again to confirm your location and see what is inside..

## Practice commands
```bash
pwd
ls
mkdir my-project
cd my-project
pwd
```
